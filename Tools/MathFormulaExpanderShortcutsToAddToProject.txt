"Q: How do we verify that an inverted matrix that we find is "italic{actually}" an inverse?"
newline
"A: You ensure that the following (bolded) line holds true!"
newline
"   " bold{A A^{-1} ~=~ A^{-1} A ~=~ I}
newline
"   " A A^{-1} = I "   "italic{"and simultaneously"}"    "A^{-1} A = I     size * 0.75"      (Equivalent to above line)"
newline
"   " MatrixA cdot MatrixA^{Inverse} ~=~ MatrixA^{Inverse} cdot MatrixA ~=~ IdentityMatrix     size * 0.75"      (Equivalent to above line)"
newline
"" size * 0.75{"> The "cdot" corresponds to matrix multiplication, NOT to elementwise multiplication."}
newline
"" size * 0.75{"> Note: \"Inverse\" is sometimes NOT the same as \"Left Inverse\", and is sometimes NOT the same as \"Right Inverse\"."}

%% 4x4 Permutation Matrix Example
%% Permutation matrices always start out as Identity matrices.
%% * Each element of I is either 1 or 0: Main diagonal is all 1s, and all non-main-diagonal elements are 0s.
%% Starting from the I matrix, you swap its *rows* (not columns, though that can achieve the same effect)
%%   , in whatever fashion you like, to get a permutation matrix.
%% In the below example:
%% * Red   row was originally row3 (2nd from bottom).
%% * Green row was originally row1 (top row).
%% * Blue  row was originally row2 (2nd from top).

left [
matrix{
   color red   0 # color red   0 # color red   1 # color red   0
## color green 1 # color green 0 # color green 0 # color green 0
## color blue  0 # color blue  1 # color blue  0 # color blue  0
## 0 # 0 # 0 # 1}
right ]
